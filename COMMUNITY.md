## ðŸ’¡ The RFC System (Request for Comments)
Major features in Zenvu.js are driven by the community through the RFC process.
If you want to propose a radical change to the Reactivity system or the Rust Compiler, please submit an RFC issue using the `RFC Proposal` issue template. We discuss it, refine it, and then implement it together.

We rigorously organize our issues so you can find exactly where to contribute:
- `good first issue`: Great for newcomers to Rust or TS.
- `help wanted`: Core team needs community assistance.
- `compiler:rust`: Related strictly to `crates/zenvu-compiler`.
- `runtime:ts`: Related strictly to `packages/runtime-core`.
- `security`: Needs immediate security team review.
